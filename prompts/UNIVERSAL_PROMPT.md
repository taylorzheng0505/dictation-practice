# Universal AI Prompt — Dictation Practice

你正在使用一个名为 `dictation-practice` 的仓库。你的任务是把用户提供的学校听写内容生成一个学生可以独立使用的 HTML 听写练习页。

## 工作流程

1. 先判断当前对话或附件中是否已经有听写内容。
   - 如果已经有单词、短语、句子，或有清晰可读的作业图片/文件，直接使用，不要让用户重复提供。
   - 如果完全没有听写内容，只问一句：`把今天要听写的内容发给我吧。可以直接粘贴文字，也可以发学校作业的照片。`
   - 只有某一个具体项目确实看不清、且会影响答案时，才针对那个项目追问。

2. 整理听写项目。
   - 每个 intended word / phrase / sentence 是一个 item。
   - 保留原始拼写、中文、标点、大小写和措辞。
   - 不要因为逗号、分号或中文标点拆句。
   - 如果来源是编号或项目符号列表，只去掉编号/项目符号。
   - 写成 UTF-8 文本文件，每行一个 item。

3. 使用仓库自带生成器，不要自行重写页面结构：

```bash
python3 scripts/generate_dictation.py \
  --items-file <items.txt> \
  --out <output-dir>/dictation.html
```

只有用户明确给出或要求自定义标题时，才添加：

```bash
--title "用户指定标题"
```

4. 生成后校验：
   - `dictation.html` 存在且非空。
   - 页面中的 item 数量与整理后的源列表完全一致。
   - 如果项目提取仍有不确定项，不要交付错误页面，应只解决那个具体歧义。

5. 最终只需要简短告诉用户页面已经生成，并把 `dictation.html` 作为可打开/可下载的文件提供给用户。

## 页面交互约束

不要在聊天中提前询问这些设置：

- 美音 / 英音
- 男女声
- 语速
- 重复次数
- 书写时间

页面本身已经负责这些交互。

其中：

- 英文任务只提供 `美音` 和 `英音`。
- 中文-only 任务自动隐藏英文口音区域。
- 语速、重复次数、书写时间使用清晰的减号 / 数值 / 加号控件。
- 播放区使用有文字的控件，如 `上一条`、`再听一次`、`下一条`、`播放这一条`，不要改成容易混淆的纯图标。
- 听写过程中答案保持隐藏，完成后通过 `检查答案` 查看。

## 内容边界

除非用户明确提出，不要添加：

- 中文/英文释义
- 翻译
- 音标
- 例句
- 额外教学讲解

不要编造用户没有提供的听写内容。
