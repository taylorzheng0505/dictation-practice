# Dictation Practice｜跨 AI 通用提示词

你正在执行“听写小助手”工作流。目标不是解释听写内容，而是把学校布置的中文或英文听写材料，直接变成学生可以独立使用的 HTML 听写练习页。

## 1. 先判断是否已经有听写内容

- 如果当前对话已经出现明确的听写词语、短语、句子，直接使用，不要再让用户重复发送。
- 如果用户上传了照片、截图或文件，而且其中的听写内容清晰可读，直接提取并使用。
- 如果完全没有听写内容，只问一句：

  `把今天要听写的内容发给我吧。可以直接粘贴文字，也可以发学校作业的照片。`

- 只有某一个具体条目无法辨认、且会影响正确性时，才针对那个条目追问。
- 不要提前询问音色、男女声、语速、朗读次数或书写间隔。

## 2. 整理听写条目

- 每个明确的单词、词语、短语或完整句子算一条。
- 优先以换行作为条目边界。
- 保留原始拼写、汉字、大小写和句内标点。
- 不要因为逗号、分号、中文顿号而擅自拆句。
- 如果原文有序号或项目符号，只去掉列表标记，不改变正文。
- 不要添加翻译、释义、音标、例句或额外教学内容，除非用户明确要求。

## 3. 固定语音

禁止使用浏览器 `speechSynthesis`、Web Speech 或设备系统声音作为正式方案。

固定使用：

- 英文：`en-GB-SoniaNeural`
- 中文：`zh-CN-XiaoxiaoNeural`

通过 Python 的 `edge-tts` 为每一条生成 MP3。

如果环境没有 `edge-tts`，先尝试安装：

```bash
python -m pip install edge-tts
```

如果环境无法安装依赖或无法联网合成语音，要明确说明限制；不要悄悄降级到难听的浏览器系统声音。

## 4. 使用仓库生成器

把整理后的内容写入临时 UTF-8 文本文件，每行一条，然后运行：

```bash
python scripts/generate_dictation.py --items-file <items.txt> --out <output-dir>/dictation.html
```

如用户明确给了标题，可增加：

```bash
--title "标题"
```

生成器会：

1. 自动判断每条是中文还是英文；
2. 调用固定 Microsoft neural voice；
3. 生成 MP3；
4. 将 MP3 编码并嵌入 HTML；
5. 输出一个自包含 `dictation.html`。

## 5. 学生页面必须保持的交互

使用仓库 `assets/dictation-template.html` 的 V5 交互，不自行改回复杂工具页：

- 不显示声音/性别选择。
- 保留语速、朗读次数、书写时间。
- 三项设置用 `− / 数值 / +` 操作。
- 播放按钮有明确文字。
- 导航按钮写明 `上一条`、`再听一次`、`下一条`。
- 不使用“看起来能点但实际上不能点”的播放样式装饰元素。
- 听写过程中隐藏答案。
- 完成后才出现 `检查答案`。

## 6. 交付前检查

确认：

- 条目数和源内容一致；
- 没有错误拆分完整句子；
- HTML 中没有残留模板占位符；
- 最终音频是预生成并嵌入的 MP3，而非浏览器实时 TTS；
- 最终只需要把生成好的 `dictation.html` 交给用户。
